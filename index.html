Accessible UI Kit

Five interface components in plain JavaScript. Each one starts as ordinary HTML that works without scripts, then follows the WAI-ARIA Authoring Practices once the script runs. Every component has keyboard and axe-core tests, and the styles cover light and dark schemes, reduced motion, and Windows high contrast.

  • 5 Components Accordion, tabs, dialog, combobox, navigation
  • 0 Runtime dependencies No framework, no build step
  • 3 Engines tested Chromium, Firefox, WebKit
  • 2.7 kB JavaScript All five components, gzipped

Accordion

Headings become toggle buttons, so heading navigation still works. Collapsed answers still turn up in find in page, and without JavaScript every answer simply shows.

Source src/accordion.js

How fast do orders ship?

Orders placed before 2 p.m. Central ship the same business day.

Can I return something?

Return anything unused within 30 days for a full refund.

Is there a warranty?

Every bag carries a two-year warranty against defects.

Tabs

Plain sections become a tab list, each tab named by its section's heading. Arrow keys switch tabs and only the selected tab sits in the tab order. Without JavaScript the sections stack.

Dialog

The native dialog element does nearly all of the work: the button opens it with no script at all, the page behind goes inert, and Escape or a click outside closes it. The script returns focus where Safari would lose it and covers older browsers.

Source src/dialog.js

Dialog keyboard support
KeyAction
EscapeClose and return to the button
TabStays inside the dialog

Combobox

Starts life as an input with a native datalist, so suggestions work without JavaScript. Once enhanced, focus stays in the field while arrow keys move through matches, and a live region announces the result count.

Source src/combobox.js

Combobox keyboard support
KeyAction
Down and UpMove through matches
EnterPick the highlighted match
EscapeClose the list, then clear the field

Navigation

The menu at the top of this page. It follows the disclosure navigation pattern instead of an ARIA menu, so links stay links for screen reader users. Submenus close when focus or a click lands anywhere else.

Source src/disclosure-nav.js

Navigation keyboard support
KeyAction
Enter or SpaceOpen or close a submenu
Down and UpMove through the open submenu
EscapeClose and return to its button
